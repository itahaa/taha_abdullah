## Status Definitions

| Status | Meaning | Action Required |
|--------|---------|----------------|
| **RESEARCH** | Evaluating product, no ads live | Complete product profile below before spending |
| **TESTING** | First creative batch live, gathering data | Read at day 3. Min 3 creatives running. |
| **OPTIMIZING** | Winner found, iterating on angle | Scale winner, test 3 new variations |
| **SCALING** | ROAS ≥ 1.8 confirmed. Ramping budget | Increase 20–30% per 48 hours max |
| **MAINTAINING** | Steady state, monitoring for fatigue | Weekly creative refresh check |
| **PAUSED** | Temporarily halted (seasonal/stockout) | Set resume date. Note reason. |
| **KILLED** | Product failed. Do not revive without major change | Archive with learnings |
